# db/migrations

This directory contains Prisma migration files — auto-generated by `prisma migrate dev`.

Migrations are generated when you run:
```bash
cd apps/backend
npm run db:migrate
# → enters migration name prompt (e.g. "initial_schema")
```

The generated SQL files will appear here as:
```
db/migrations/
└── 20240901_initial_schema/
    └── migration.sql
```

> **Do not edit migration files manually.**
> Prisma uses these files to track DB schema history.
